## Hi, I'm Bhumit Sheth 👋

![Profile views](https://komarev.com/ghpvc/?username=shethbhumit&label=Profile%20views&color=9f7be1&style=flat)

**Analytics engineer at heart, working on a data engineering & analytics team at a consumer fintech.**
I build the layer between raw data and decisions: master tables and datamarts that act as a single source of truth, governed metric definitions, and tested pipelines that people (and AI agents) can trust.

- 🧱 **What I build:** dimensional models (dim/fact, SCD2), datamarts, incremental loads, Airflow DAGs with tests and CI/CD
- 📊 **Recent work:** a KPI scorecard for 1,000+ employees, built on master tables I designed for conversation, QA, and customer-satisfaction data
- 🤖 **AI-native:** I use Claude Code daily and design models and documentation for both analysts and LLM consumers
- 📚 **Currently learning:** dbt (incremental models, tests, macros) and Databricks semantic metrics
